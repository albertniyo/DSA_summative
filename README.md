# DSA_summative

ALU DSA in C summative project. Each folder is a standalone program with `main.h`, `main.c`, and `questionN.c`.

| Folder | Topic |
|--------|-------|
| [question1](question1/) | Embedded Device Event Logger (doubly linked list) |
| [question2](question2/) | Network Device Command Registry (BST) |
| [question3](question3/) | Server Dependency Network Analyzer (directed graph) |
| [question4](question4/) | Emergency Medical Supply Routing (Dijkstra) |
| [question5](question5/) | Firmware Log Compression (Huffman) |

## How to run any question

```bash
cd questionnber
gcc main.c questionnber.c -o program_name
./program_name
```

See each folder’s `README.md` for the exact compile command and usage.
